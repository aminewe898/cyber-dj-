# Historical ESP32 controller prototype

Archived after consolidation into [Mini DJ Controller](https://github.com/aminewe898/mini-DJcontroller).

All original tracked files, including source, documentation, case material or demonstration media, are preserved under [`legacy/cyber-dj/`](https://github.com/aminewe898/mini-DJcontroller/tree/main/legacy/cyber-dj). Original commits were imported without squashing or changing authorship.

This iteration controls PWM lighting over ESP32 BLE. It does not implement AI processing or audio mixing. Continue from the canonical repository and read its status/limitations before reproducing hardware.
