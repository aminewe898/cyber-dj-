## 🚀 What this project aims to become

Cyber-DJ blends **hardware**, **web tech**, and **AI** to create a next-gen DJ experience.  
The goal is a system that merges:

- Embedded electronics  
- Music-reactive lighting  
- AI-powered gesture tracking  
- Real-time web dashboard  
- Post-performance analytics  

Future versions will combine the ESP32 brain, web controls, and on-device AI or external AI models for gesture recognition and feedback.
